# Toolbox

Download links for the tools used in my programming classes, served at [tools.sadiqsalau.com](https://tools.sadiqsalau.com).

## Development

```bash
pnpm install
pnpm dev
pnpm build
```

## Adding a tool

Add an entry to `links` in `src/resources/links.ts`. Its `category` decides which section it appears in.
